# Анализ изменений #496

В рамках последних коммитов были добавлены следующие возможности:
- [x] Реализована процедурная генерация остатков сверхновых (SupernovaRemnant) для галактик.
- [x] Добавлен класс `SupernovaRemnant` и метод `generate_supernova_remnants` в `Galaxy`.

Технический обзор:
Проект продолжает расширять свои возможности по симуляции объектов вселенной. Был добавлен класс `SupernovaRemnant`, представляющий остаток сверхновой. В классе `Galaxy` обновлен метод `__init__`, добавлено свойство `self.supernova_remnants` для хранения списков остатков сверхновых, а также метод `generate_supernova_remnants` для их процедурной генерации с заданными параметрами.
