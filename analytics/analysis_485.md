# Анализ изменений: Процедурная генерация микроквазаров

## Выполненные задачи
- Добавлен класс `Microquasar` для представления микроквазаров в галактиках.
- В класс `Galaxy` добавлен метод `generate_microquasars` для процедурной генерации микроквазаров.
- Добавлены тесты в `tests/test_galaxy.py` для проверки генерации микроквазаров.
- Обновлен файл `agents.md` с отметкой о выполнении задачи.
- В `CHANGELOG.md` добавлена запись о новой функциональности.

## Технический обзор
- Реализована базовая структура `Microquasar` с атрибутами `name` и `radius`.
- Метод `generate_microquasars` использует случайные значения радиуса в диапазоне от 100 до 10000.
- Изменения покрыты модульными тестами с использованием `unittest`. Все тесты проходят успешно, подтверждая отсутствие регрессий.
