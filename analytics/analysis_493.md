# Анализ изменений: Генерация красных гигантов

## Описание
Был реализован алгоритм процедурной генерации красных гигантов в классе `Galaxy`.
Это включает создание нового класса `RedGiant` и метода `generate_red_giants`,
добавляющего указанное количество красных гигантов в список `red_giants` галактики.

## Выполненные задачи
- Добавлен класс `RedGiant`.
- Реализован метод `generate_red_giants` в классе `Galaxy`.
- Добавлены тесты для проверки корректности генерации красных гигантов.
