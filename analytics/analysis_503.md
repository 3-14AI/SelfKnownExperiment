# Анализ изменений: Генерация красных сверхгигантов

## Технический обзор
В рамках расширения процедурной генерации вселенной был добавлен новый класс `RedSupergiant`. Этот класс представляет красные сверхгиганты — массивные звезды на поздних стадиях эволюции.

В класс `Galaxy` добавлен метод `generate_red_supergiants`, который позволяет генерировать заданное количество красных сверхгигантов со случайным радиусом в диапазоне от 500000 до 2000000 условных единиц.

## Выполненные задачи
- Реализован класс `RedSupergiant`.
- Добавлен метод `generate_red_supergiants` в класс `Galaxy`.
- Написаны изолированные тесты для проверки корректности генерации и свойств красных сверхгигантов в `tests/test_galaxy.py`.
- Тесты успешно пройдены, что подтверждает работоспособность нового функционала.
