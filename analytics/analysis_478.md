### Analysis 478: Внедрение процедурной генерации планет-сирот в галактиках

**Завершенные задачи:**
- Добавлен класс `RoguePlanet` в `src/universe/galaxy.py` для представления планет-сирот (rogue planets), дрейфующих в межзвездном пространстве.
- Добавлен метод `generate_rogue_planets` в класс `Galaxy` для вероятностной генерации и добавления планет-сирот в галактику.
- Добавлен тест `test_rogue_planet_generation` в `tests/test_galaxy.py` для проверки корректности создания планет-сирот.
- Обновлены файлы `agents.md` и `CHANGELOG.md` для отражения новой реализованной функциональности.

**Технические детали:**
Реализовано дальнейшее расширение структуры процедурной генерации космоса. Галактики теперь могут содержать планеты-сироты, имеющие радиус, генерируемый случайным образом (от 1000 до 10000). Метод `generate_rogue_planets` позволяет указывать количество планет-сирот для генерации. Имена объектов формируются по шаблону `RoguePlanet-<Индекс>`. Тестирование подтверждает корректность создания объектов `RoguePlanet` и их успешную привязку к классу `Galaxy`.
