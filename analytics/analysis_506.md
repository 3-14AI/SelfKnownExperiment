# Анализ: Процедурная генерация протозвёзд (Protostar)

## Обзор
Был реализован новый класс `Protostar` для представления протозвёзд в симуляторе вселенной.
Также в класс `Galaxy` добавлен метод `generate_protostars` для их процедурной генерации в рамках галактики.

## Детали реализации
- Добавлен класс `Protostar` в `src/universe/galaxy.py`.
- Добавлен атрибут `protostars` (список) в конструктор `Galaxy`.
- Добавлен метод `generate_protostars` в `Galaxy`.
- Написаны unit-тесты в `tests/test_galaxy.py` для проверки корректности генерации и инициализации радиуса и имени протозвёзд.
