# Анализ изменений: Генерация экзопланет (analysis_497)

## Завершенные задачи
- Добавлена процедурная генерация экзопланет (`Exoplanet`) для галактик в движке `Universe`.

## Технический обзор
- Создан класс `Exoplanet` в модуле `src/universe/galaxy.py` с атрибутами `name` и `radius`.
- Добавлен метод `generate_exoplanets` в класс `Galaxy`, который процедурно генерирует заданное количество экзопланет с радиусом в диапазоне от 50 до 500.
- Добавлена инициализация списка `exoplanets` в конструкторе `Galaxy`.
- Разработан юнит-тест `test_exoplanet_generation` в `tests/test_galaxy.py` для проверки корректности создания, количества и атрибутов генерируемых экзопланет.
- Проведено полное тестирование — все тесты завершены успешно.
