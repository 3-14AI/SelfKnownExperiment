# Анализ изменений: Генерация нейтронных звезд

## Выполненные задачи
- Реализована процедурная генерация нейтронных звезд в галактиках.
- Добавлен класс `NeutronStar`.
- В класс `Galaxy` добавлен метод `generate_neutron_stars`.
- Добавлены соответствующие тесты.

## Технический обзор
Был добавлен класс `NeutronStar` для представления нейтронных звезд. В классе `Galaxy` обновлен метод `__init__` для инициализации списка `neutron_stars`, а также добавлен метод `generate_neutron_stars`, который процедурно генерирует заданное количество нейтронных звезд со случайным радиусом от 10 до 50. Написаны юнит-тесты для проверки корректности генерации и инициализации объектов нейтронных звезд.
